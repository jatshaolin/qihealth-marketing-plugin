## Cómo se actualiza este documento

- **Trimestral**: revisión de targets con Jose. Ajuste según realidad.
- **Mensual**: el sistema reporta diff entre target y actual. Si el sistema detecta deviation >25% en cualquier métrica por 3 semanas seguidas, alerta a Jose para revisión.
- **Cuando cambian benchmarks de industria**: el plugin no asume verdades fijas. Si el equipo recibe nuevos benchmarks (de plataformas o de la agencia saliente), se incorporan aquí.
